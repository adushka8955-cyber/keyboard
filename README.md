# Клавиатура Фразы (Android)

Клавиатура (RU / EN) с подсказками слов, автоисправлением, темами в стиле iPhone и Android и панелью готовых фраз и смайлов (кнопка **«Фразы»**).

## Как получить APK

**Вариант 1. Android Studio**
1. File → Open → выберите папку проекта, дождитесь синхронизации Gradle.
2. Подключите телефон (отладка по USB) и нажмите Run, либо Build → Build APK(s).
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

**Вариант 2. Командная строка** (нужны JDK 17 и Android SDK 34)
```
./gradlew assembleDebug
```

**Вариант 3. Без установки чего-либо — GitHub Actions**
1. Загрузите папку проекта в новый репозиторий на GitHub.
2. Вкладка Actions → «Build APK» → дождитесь зелёной галочки.
3. Скачайте артефакт `PhraseKeyboard-apk` внутри запуска — там `app-debug.apk`.

## Как включить на телефоне
1. Установите APK (разрешите установку из неизвестных источников, если спросит).
2. Откройте приложение «Клавиатура Фразы» → «Открыть список клавиатур» → включите её.
3. «Выбрать клавиатуру» → выберите «Клавиатура Фразы».
4. В любом чате нажмите синюю кнопку «Фразы».

## Что умеет
- **Подсказки слов (T9-стиль)**: над клавишами три варианта, по мере набора и при опечатке. Тап по варианту заменяет слово. Словари: ~110 тыс. русских и ~70 тыс. английских слов (работают без интернета).
- **Автоисправление опечаток** на пробеле и знаках. Нажали «стереть» сразу после исправления — вернётся ваш вариант, и слово запомнится. «Забыть выученные слова» — в настройках.
- **Умная пунктуация**: убирает пробел перед `, . ! ?`, точка по двойному пробелу, пробел после запятой, заглавная буква в начале предложения. Запятые по правилам грамматики автоматически не ставятся.
- **Темы**: iPhone светлая/тёмная, Android светлая/тёмная, AMOLED, зелёная, песочная, розовая, мятная, градиенты (закат, океан, ночное небо, фиолетовая) и **своё фото на фон**. Маленькая стрелка слева над клавишами открывает меню «Фразы / Тема / Настройки»; «Тема» переключает оформление прямо в чате.
- **Стиль iPhone**: раскладка, тени клавиш и увеличенная буква при нажатии. Переключается на Android-раскладку в настройках.
- Высота и форма клавиш, ряд цифр сверху, вибрация.
- Панель **«Фразы»**: приветствия, благодарности, зикр и дуа и другое, свои фразы (вкладка «Мои») и смайлы.
- Буквы RU/EN, цифры и символы, Shift (двойное нажатие — Caps Lock), долгое нажатие на «е» — «ё».
- **Пробел**: свайп влево/вправо меняет язык, долгое нажатие — выбор другой клавиатуры. Рядом с пробелом клавиши «,» и «.». Кнопка с мечетью слева открывает панель фраз и смайлов.
- В полях паролей, e-mail и адресов подсказки и автоисправление отключены.

## Как обновить уже загруженный проект на GitHub
1. Распакуйте архив и откройте папку проекта.
2. В репозитории: Add file → Upload files, перетащите всё содержимое папки (Ctrl+A), нажмите Commit changes. Файлы с теми же именами заменятся, папку `.github` повторно загружать не нужно.
3. Во вкладке Actions дождитесь новой сборки и скачайте APK.

## Как изменить встроенные фразы
Откройте `app/src/main/java/app/phrasekeys/PhraseLibrary.kt` и правьте список `builtIn`:
категории и фразы там записаны обычным текстом.

## Версия 2.2
- Верхняя полоска теперь тонкая: в покое видна только маленькая стрелка слева. Когда печатаешь — вырастают подсказки.
- Нажми на стрелку — снизу выезжает меню с пунктами: Фразы, Смайлы, Тема, Настройки, Ряд цифр, Размер букв, Высота, Клавиатура.
- Символы: три страницы (1/3, 2/3, 3/3) — кнопка слева в третьем ряду листает страницы.
- Буквы и цифры меньше; в Настройках можно выбрать размер (мелкие / средние / крупные).
- Ряд цифр сверху включён по умолчанию.

## Версия 2.3
- «Мои данные»: в Настройках впиши почту, имя, фамилию, отчество, ФИО, телефон, даты. Они в панели (вкладка «Данные», быстрый доступ — стрелка → «Данные»). В поле почты и телефона сами предлагаются в подсказках.
- Клавиатура запоминает, что ты часто отправляешь: фразы, почты, телефоны, даты. После второго раза они появляются в подсказках (начни печатать — предложит целиком) и во вкладке «Частые» (долгое нажатие — убрать).
- Пароли, коды из СМС и номера карт не запоминаются. Всё хранится только на телефоне; в Настройках можно выключить или стереть.

## Версия 2.4
- Новые нарисованные значки вместо эмодзи: меню, мечеть, стрелки (шифт, стереть, ввод, пробел). Чёрные круги за значками убраны.
- «Стеклянные» выпуклые клавиши в стиле iPhone: мягкий градиент, блик, светлая кромка, тень. Выключатель — в Настройках («Стеклянные объёмные клавиши»).
- Две новые темы: «Стекло тёмное» и «Стекло светлое».
- Ряд цифр и символов выровнен по ширине с буквами.

## Версия 2.5
- Подсказки (Т9) и автоисправление теперь работают и в Instagram: приложение просило клавиатуру их отключить, теперь это игнорируется (кроме паролей). Выключатель — в Настройках.
- Подсказки обновляются надёжнее, даже если приложение не сообщает о движении курсора.
- Между «!#1» и мечетью появилась кнопка смайлов; пробел стал короче.

## Версия 2.6
- Быстрее: буквы печатаются сразу при касании; клавиатура делает один запрос к приложению вместо пяти; регистр букв и подсказки перерисовываются только при изменении; высота верхней полоски больше не прыгает; нажатые клавиши и пузырёк буквы рисуются без лишних перерасчётов.
- Предсказание слов по смыслу: после слова предлагается следующее («как» → «дела»), а при наборе подсказки учитывают предыдущее слово. Клавиатура учится на ваших отправленных сообщениях.
- Буфер обмена: скопировали ссылку, слово или предложение — сверху появляется плашка с иконкой буфера, нажмите, чтобы вставить. Последние копии лежат во вкладке «Буфер» (стрелка → «Буфер»).
