# Клавиатура Фразы (Android)

Обычная клавиатура (RU / EN, цифры и символы) с кнопкой **«Фразы»** в нижнем ряду.
Нажали кнопку — открылась панель с готовыми фразами по категориям, тап по плашке вставляет текст в поле ввода. Кнопка **«АБВ»** возвращает к буквам.

## Как получить APK

**Вариант 1. Android Studio**
1. File → Open → выберите папку проекта, дождитесь синхронизации Gradle.
2. Подключите телефон (отладка по USB) и нажмите Run, либо Build → Build APK(s).
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

**Вариант 2. Командная строка** (нужны JDK 17 и Android SDK 34)
```
./gradlew assembleDebug
```

**Вариант 3. Без установки чего-либо — GitHub Actions**
1. Загрузите папку проекта в новый репозиторий на GitHub.
2. Вкладка Actions → «Build APK» → дождитесь зелёной галочки.
3. Скачайте артефакт `PhraseKeyboard-apk` внутри запуска — там `app-debug.apk`.

## Как включить на телефоне
1. Установите APK (разрешите установку из неизвестных источников, если спросит).
2. Откройте приложение «Клавиатура Фразы» → «Открыть список клавиатур» → включите её.
3. «Выбрать клавиатуру» → выберите «Клавиатура Фразы».
4. В любом чате нажмите синюю кнопку «Фразы».

## Что умеет
- Буквы RU/EN, цифры и символы, Shift (двойное нажатие — Caps Lock), автозаглавная в начале предложения.
- Долгое нажатие на «е» — «ё». Долгое нажатие на RU/EN — системный выбор клавиатуры.
- Удаление с автоповтором, Enter использует действие поля («Отправить», «Поиск» и т. д.).
- Светлая и тёмная тема по настройкам системы.
- Вкладка **«Мои»**: свои фразы, по одной на строку (в приложении, раздел «Мои фразы»).

## Как изменить встроенные фразы
Откройте `app/src/main/java/app/phrasekeys/PhraseLibrary.kt` и правьте список `builtIn`:
категории и фразы там записаны обычным текстом.
